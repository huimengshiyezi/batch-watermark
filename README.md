# 批量加水印

一次给**多张图片**加上**文字水印**或**图片水印**：位置、大小、透明度、旋转统一设置，处理完自动打包成一个 ZIP 下载。

> **纯本地处理 · 文件不上传 · 断网可用** —— 所有运算都在你自己的浏览器里完成，图片不会离开这台设备。

## 快速开始

| 入口 | 怎么用 |
|---|---|
| **在线使用** | 打开 `https://huimengshiyezi.github.io/batch-watermark/`（本仓库开启 GitHub Pages 后就是该地址） |
| **下载使用**（推荐） | 下载 [`index.html`](index.html)，双击用浏览器打开即可，**断网也能用** |
| **最新版本** | [Releases · 最新版](../../releases/latest) |

> 下载方式二选一：直接保存 `index.html` 单文件（整个工具就这一个文件），或者从 Releases 页面下载打包好的 zip。

## 它能做什么

| 能力 | 说明 |
|---|---|
| 批量选图 | 点击选择或**直接拖进来**，一次几十张；支持 JPG / PNG / WebP |
| 文字水印 | 内容、字号、颜色、透明度、旋转；可选**描边**、**阴影** |
| 图片水印 | 上传一张图（推荐透明底 PNG）当水印，可调大小、透明度、旋转 |
| 位置 | **九宫格**九个位置任选，或切换成**平铺**铺满整张画面 |
| 边距 | 水印离图片边缘的距离可调 |
| 实时预览 | 改参数立即看到效果；点缩略图可切换查看任意一张；显示「第 N / 共 M 张」 |
| 批量导出 | 一键处理全部 → **打包成 ZIP 下载**；也可以只下载当前这一张 |
| 输出格式 | 原格式 / 统一 JPG（带质量滑块）/ 统一 PNG |
| 文件名 | 原名 + 后缀（默认 `_wm`），后缀可以自己改，重名会自动加序号 |
| 进度指示 | 显示「正在处理第 N / 共 M 张」，大图不会让你干等 |

## 三步上手

1. **选图片**：把要处理的图拖到第一个框里（或点一下选择）。
2. **调水印**：切「文字水印」写上你的字，或者切「图片水印」传一张 logo；然后在九宫格里点一下水印要待的位置。
3. **导出**：点「一键处理全部 → 打包下载 ZIP」，浏览器会自动下载一个 `watermarked_日期_时间.zip`。

> 只想导出一张？在缩略图里点一下那张图，再点「只下载当前这张」。

## 参数说明（都是大白话）

| 参数 | 是什么意思 |
|---|---|
| 字号 / 大小 | 水印在图片上占多大。**按图片短边的百分比算**，所以大图小图效果一致，不用每张重设 |
| 不透明度 | 水印的浓淡。数字越小越淡（越不容易挡住画面） |
| 旋转角度 | 水印倾斜多少度，`-180°` 到 `180°`；平铺模式下常用 `-30°` 左右 |
| 描边 | 给文字描一圈边，浅色水印压在亮背景上也能看清 |
| 阴影 | 给文字加投影，压在有花纹的背景上更清楚 |
| 边距 | 水印离图片边缘留多少空，**同样按图片短边百分比算** |
| 平铺 | 水印斜着一排排铺满整张图，适合防搬运；勾上后九宫格位置就不起作用了 |
| 后缀 | 输出文件名多出来的那一截，默认 `_wm`（`照片.jpg` → `照片_wm.jpg`） |
| JPG 质量 | 只对 JPG 生效，数字越高越清楚、文件越大；PNG 是无损的，没有这个选项 |

## 输出说明

- **原格式**：JPG 还是 JPG、PNG 还是 PNG、WebP 还是 WebP。
- **统一 JPG**：所有图都变成 JPG，透明区域会填成白色（JPG 不支持透明）。
- **统一 PNG**：所有图都变成 PNG，体积通常比 JPG 大。
- 极个别格式浏览器编不出来时会自动退回 PNG，并在文件扩展名上体现，不会生成打不开的文件。
- ZIP 里的中文文件名正常显示（文件名按 UTF-8 写入）。

## 性能与内存

这个工具是**一张一张顺序处理**的，不是一次性把所有图都读进内存：

- 同一时刻只解码 1 张原图，画完立刻把 Canvas 和 ImageBitmap 释放掉；
- 列表里只保留 96 像素的小缩略图，不保留大图；
- 预览用的是一张缩小到 1000 像素以内的小画布，拖参数不会重新解码原图；
- 处理过程中每张之间会让出一次浏览器主线程，进度条能实时刷新，页面不会假死。

**单张长边超过 4000 像素**会标上「大图」提示：能处理，但会更慢、更吃内存，建议一次别放太多张。

## 已知限制

- 打包 ZIP 需要把所有**处理结果**同时留在内存里（ZIP 格式本身就是这么组织的），所以一批图的**输出总体积**过大时（超过约 1.2 GB）会拒绝打包并提示分批处理 —— 原图始终是逐张解码、逐张释放的。
- 不支持 GIF、HEIC、AVIF、BMP 等格式（浏览器能不能解码就用不了），拖进来会被跳过。
- 手机相册里的 HEIC 照片请先转成 JPG 再用。
- WebP 输出依赖浏览器编码器（Chrome / Edge / Firefox 都支持；个别旧浏览器会自动退回 PNG）。
- 图片水印目前只支持整张图直接贴，没有抠图 / 去除白底功能，所以**建议自己先准备好透明底 PNG**。
- 预览是缩小显示的，像素级细节（比如 1 像素的描边发虚）以导出结果为准。
- 超大尺寸图片受浏览器单张 Canvas 上限约束（Chrome 约 16384 像素），超过会处理失败。

## 浏览器要求

Chrome / Edge 90+、Firefox 113+、Safari 16.4+。手机浏览器（iOS Safari / Android Chrome）同样可用，界面按手机竖屏做过适配。

## 技术实现

- **零依赖单文件**：CSS / JS 全部内联在 `index.html` 里，没有构建步骤、没有 CDN、没有第三方库。
- **水印绘制**：Canvas 2D 的 `drawImage` / `fillText` + `strokeText`，投影用 `shadowBlur`，透明度用 `globalAlpha`。
- **图片解码**：优先 `createImageBitmap`（带 EXIF 方向处理，手机竖拍照片不会躺倒），不支持时退回 `Image` + `URL.createObjectURL`。
- **ZIP 打包**：自己实现的 store 模式 ZIP（CRC32 查表 + 本地文件头 + 中央目录 + EOCD），文件名带 UTF-8 标记位，不引入任何压缩库。

## 隐私说明

- 所有处理都在浏览器本地完成，图片**不会**上传到任何服务器；
- 没有后端、没有数据库、没有统计代码，页面不发任何网络请求；
- 把 `index.html` 存到本地，断网（拔网线 / 关 Wi-Fi）也能照常使用；
- 代码全部在这个文件里，可自行打开查看。
